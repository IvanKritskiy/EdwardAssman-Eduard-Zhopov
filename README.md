# EdwardAssman-Eduard-Zhopov
Проект сохранения светлой памяти мэтра Русской поэззии, литературы, кинематографа, музыки, шахмат, и вообще всего Русского. Эдуард Жопов - наше всё. Вечная память Глыбе

## Архив Эдуарда Жопова

Статический сайт-архив, собранный из экспорта телеграм-канала «Писатель Эдуард Жопов» (`Эдуард Жопов/messages.html`, `messages2.html`). Готовый сайт лежит в папке `docs/`.

Разделы:

- **Жизнеописание**: биография по документам и хронология, у каждого факта номер записи-источника;
- **Собрание сочинений**: рассказы Мэтра по томам и годам, эссе, библиография романов, приложение с прозой Ягодичкина;
- **Стихотворения и песни**, **Свидетельства современников**, **Окружение**, **Заветы**;
- **Премия имени Жопова** и **Вопросы читателей**: подборки, собранные по ключевым словам;
- **Фотоархив**: опись всех записей с изображениями;
- **Летопись**: все записи канала по месяцам.

Номер единицы хранения на сайте совпадает с номером записи в Telegram. Тексты не правятся. Номера карт и телефонов для пожертвований при сборке заменяются пометкой «изъято».

### Как посмотреть

Откройте `docs/index.html` в браузере или включите GitHub Pages: Settings → Pages → Deploy from a branch → ветка с сайтом, папка `/docs`.

### Как пересобрать

Нужен Python 3.11+ с пакетами `beautifulsoup4` и `jinja2`:

```bash
pip install beautifulsoup4 jinja2
```

```bash
python3 tools/parse_export.py "Эдуард Жопов" -o data/posts.json
```

```bash
python3 tools/build_site.py
```

Первая команда разбирает HTML-экспорт Telegram Desktop в `data/posts.json`, вторая собирает сайт в `docs/`.

### Фотографии

Сейчас в архиве только тексты, поэтому фотоархив показан описью, а на месте снимков стоят заглушки «не оцифрована». Чтобы появились изображения, положите в `Эдуард Жопов/` папку `photos/` из того же экспорта Telegram Desktop (рядом с `messages.html`) и пересоберите сайт. Сборщик сам скопирует фотографии в `docs/media/`.

### Где что лежит

| Путь | Что там |
|---|---|
| `Эдуард Жопов/` | исходный экспорт канала |
| `content/canon.toml` | кураторская разметка: тома, свидетели, люди, хронология, библиография, заветы, стихи |
| `content/texts.toml` | редакционные тексты: жизнеописание и вступления к разделам |
| `tools/parse_export.py` | разбор экспорта Telegram |
| `tools/build_site.py`, `tools/templates/`, `tools/static/` | генератор сайта, шаблоны, стили |
| `docs/` | собранный сайт |

Чтобы добавить рассказ в собрание сочинений или свидетеля, впишите номер записи канала в нужный список в `content/canon.toml` и пересоберите сайт.
